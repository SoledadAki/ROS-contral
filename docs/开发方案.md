# C21 麦轮 ROS 小车 —— 整体开发方案

更新：2026-10-28

## 1. 现状（已核实）

| 项目 | 实际情况 |
| --- | --- |
| 主控 | Jetson Orin NX 16G，Ubuntu 20.04 / L4T 35.5，宿主 ROS1 Noetic（不动） |
| 运行环境 | Docker 内 ROS2 Humble（已有 `c21/ros2-humble:nav` 镜像：Nav2 / slam_toolbox / robot_localization） |
| 底盘 | C21 麦轮，OpenRF4 (STM32F407) 下位机，`/dev/ttyTHS0` 115200 8N1；STM32 内部做麦轮逆解+PID；架空 vx/vy/wz 已实测会转、能停 |
| 协议 | 下行 `AA 55 0B 50 vx vy wz sum`（int16 大端，×1000）；蜂鸣器 0x66；舵机/云台 0x80（6 路）；上行 36 字节 `AA ... 7D`（IMU、实测速度、舵机、电压） |
| 雷达 | Slamtec C1，CP2102N，by-id 固定路径，460800，`sllidar_ros2` 已出 /scan |
| 相机 | **Orbbec Gemini 336L**（USB3.2，替代厂家 Astra Pro）|
| 云台 | 在用（走 0x80 舵机帧） |
| 语音 AIBOX | 暂缓，功能完善后再接 |
| 网络 | Jetson 不能直连 GitHub/PyPI/DockerHub；清华镜像可用 → 源码在电脑下载后传输 |

## 2. 总体架构

```
 ┌──────────── 平板 APP（Vue3 + Capacitor → APK；同时可用浏览器打开）────────────┐
 │ 遥控摇杆/云台/急停 · 实时视频 · 电量状态 · 建图 · 地图点选导航/多点巡航 ·      │
 │ 雷达避障/跟随/警卫 · 颜色追踪/巡线/二维码/AprilTag/手势/人体 · 设置            │
 └───────────────▲ WebSocket(JSON, 心跳租约)  ▲ HTTP MJPEG 视频 ──────────────────┘
                 │                            │
 ┌───────────────┴──── c21_gateway（APP 网关节点，端口 8080）──────────────────────┐
 │ 鉴权 · 状态汇总推送 · 模式管理器（启停各功能 launch）· 地图管理 · 视频编码      │
 └──────┬───────────────────────────────────────────────────────────────────────────┘
        │ ROS2 Humble（Docker，host 网络，ROS_DOMAIN_ID 统一）
 ┌──────┴──────┐   ┌──────────────┐   ┌──────────────┐   ┌───────────────────────┐
 │ 功能层       │   │ 导航层        │   │ 感知层        │   │ 安全层 c21_safety      │
 │ 雷达三模式    │   │ slam_toolbox │   │ sllidar C1   │   │ 速度仲裁(急停>APP>功能 │
 │ 视觉跟随等    │→ │ Nav2(全向)    │   │ Gemini 336L  │ → │ >导航) · 限速限加速度  │
 └─────────────┘   │ EKF          │   │ URDF/TF      │   │ · 雷达近距刹停 · 超时停 │
                   └──────────────┘   └──────────────┘   └──────────┬────────────┘
                                                                    │ /cmd_vel_safe
                                                       ┌────────────┴─────────────┐
                                                       │ c21_base 串口驱动          │
                                                       │ 300ms 超时清零 · 坏帧过滤   │
                                                       │ odom/imu/电压/云台/蜂鸣器   │
                                                       └────────────┬─────────────┘
                                                              /dev/ttyTHS0 → STM32
```

设计原则：
- 所有运动指令只经过安全层一个出口，急停优先级最高、无冷却。
- APP 采用"租约"心跳：APP 断线/切后台 0.5 s 内自动停车。
- 功能按模式互斥启动（建图 / 导航 / 雷达功能 / 视觉功能），避免 Jetson 过载。
- 成熟包优先（Nav2、slam_toolbox、sllidar_ros2、OrbbecSDK_ROS2、OpenCV），只自写胶水、安全层、厂家特色行为和 APP 网关。

## 3. Jetson 端工程（`~/c21_ws`，git 管理）

| 包 | 内容 |
| --- | --- |
| `c21_base` | 串口驱动（参考厂家 car_base + 已有 c21_protocol），里程计积分、IMU、电压、云台舵机、蜂鸣器 |
| `c21_description` | URDF（厂家 yeahbot_c21 + 实测雷达/相机外参）|
| `c21_safety` | 速度仲裁、限速、雷达刹停、超时 |
| `c21_bringup` | launch：base / sensors / mapping / navigation / 各功能；参数 yaml |
| `c21_behaviors` | 雷达避障/跟随/警卫；颜色追踪、巡线、二维码、AprilTag、手势/人体（MediaPipe）|
| `c21_gateway` | APP 网关：WebSocket + MJPEG + 模式管理 + 地图管理 |
| `docker/` | 运行镜像 Dockerfile（基于 nav 镜像 + OrbbecSDK_ROS2 + sllidar + 依赖）|
| `systemd/` | 开机自启：底盘+传感器+网关常驻 |

## 4. 平板 APP（`app/`）

- 技术：Vue 3 + Vite（界面） + Capacitor（打包 Android APK）；同一套界面也由网关在 `http://小车IP:8080` 提供，鸿蒙 NEXT 也能通过浏览器使用。
- 横屏平板布局：左侧视频/地图主视图，右侧功能面板，底部双摇杆（平移+旋转），常驻红色急停。
- 页面：连接 · 遥控 · 建图 · 导航 · 雷达功能 · 视觉功能 · 云台 · 状态/日志 · 设置（限速、IP）。

## 5. 分期计划

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| **P1 遥控闭环** | 运行镜像、c21_base、安全层、网关、APP 遥控+视频+急停+电量 | 平板上遥控小车地面低速前后/横移/旋转，断网自动停 |
| **P2 传感器与TF** | Gemini 336L 驱动、雷达方向核对、URDF 外参、EKF、云台控制 | RViz/APP 中雷达点与实物方向一致，里程计方向/比例正确 |
| **P3 建图导航** | slam_toolbox 建图/保存、Nav2 全向导航、APP 地图点选/多点巡航 | 实景建图，点选到达，障碍停止，取消立即停 |
| **P4 功能复刻** | 雷达三模式、颜色追踪、巡线、二维码/AprilTag、手势/人体控制、YOLO 识别 | 每项 APP 一键启停，目标丢失即停 |
| **P5 稳定优化** | 开机自启、日志、性能/延迟优化、自主探索；后续语音 AIBOX | 上电即用 |

## 6. 安全约定
- 默认限速：线速度 0.3 m/s、角速度 1.0 rad/s，APP 内可调上限。
